# Analysis Plan

1. Profile source volume, date coverage, keys, and missingness before joining.
2. Test shipment IDs for uniqueness and event records for valid parent shipments.
3. Define service performance as on-time delivery and data quality as missing ETA/POD incidence.
4. Segment reliability by carrier; keep cost and service measures separate from reporting-control measures.
5. Calculate refresh SLA as successful completion within 60 minutes of the scheduled run.
6. Produce a scorecard and trend image, then document decision-oriented findings and limitations.

EDA coverage: row volumes, distribution of delivery outcomes, carrier segmentation, missing-field exceptions, run-status outliers, and reporting-latency checks.
