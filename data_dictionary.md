# Data Dictionary

| Table | Grain | Key fields | Purpose |
|---|---|---|---|
| `shipments.csv` | one booked shipment | shipment_id, carrier_id, planned/actual dates, linehaul_usd | service, cost and completeness measures |
| `shipment_events.csv` | one shipment event | event_id, shipment_id, event_type, event_timestamp | source-system event trace |
| `carriers.csv` | one carrier | carrier_id, carrier_name, contracted_rate_per_mile | carrier reference data |
| `report_runs.csv` | one scheduled reporting run | run_id, scheduled_at, completed_at, status | automation and SLA monitoring |

`eta_missing_flag` and `pod_missing_flag` represent synthetic completeness exceptions. `on_time_flag` is 1 when actual delivery is on or before planned delivery. All records are synthetic and generated by `scripts/generate_data.py` with a fixed seed.
